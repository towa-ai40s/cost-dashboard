# 原価ダッシュボード v0.1（6本目 / 実物ツール1本目）

材料の値段を1か所直すと、全メニューの原価・粗利・原価率がその場で計算し直される。
目標原価率を超えたメニューは赤くなり、上に警告が出る。

- 公開URL: https://cost-dashboard-3f1.pages.dev
- 消す仕事: 仕入れ値が変わるたびに、電卓とExcelを行き来して全メニューを検算する手間
- 元になった資産: `financial/ライダーズカフェ深沢_原価計算表.xlsx`（材料マスタ／メニュー原価計算／原価サマリ）
- 学習テーマ: 手元のExcel資産をWebに繋ぐ（学びガイド §W6）
- 2026年10月の開業から実運用する予定（2026-08-25 補助金採択）

## 計算

    1単位の単価 = 買った値段 ÷ 買った量
    1杯の原価   = Σ（1単位の単価 × 1杯の使用量）

## ⚠️ 公開に関する決めごと

- `public/` に生活圏の地名・旧名称（深沢等）・個人情報を書かない
- **公開版の仕入れ値はすべて架空**。メニューの売価だけは公開情報なので実値
- 入力値は localStorage に保存され、外部には送信しない（外部APIを使わない設計）
